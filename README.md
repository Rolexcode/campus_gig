# CampusGig

CampusGig is a student gig marketplace with school verification, protected
payments, local settlement options, and optional USDC settlement on Solana.

## Local preview

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm run start
```

## Vercel Drop

1. Open <https://vercel.com/drop>.
2. Drag this complete `campusgig-vercel` folder onto the page.
3. Keep the detected framework as Next.js.
4. Deploy and share the generated URL.

GitHub is not required for this drag-and-drop deployment.
