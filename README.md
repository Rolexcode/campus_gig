# CampusGig

CampusGig is a student-focused freelance marketplace that helps clients find talent and helps students discover paid work opportunities.

Clients can post gigs and review applications, while students can create profiles, apply for work, complete projects, and build a reputation through their experience.

CampusGig aims to make it easier for students to turn their skills into meaningful work and for clients to connect with emerging talent.

[Visit CampusGig](https://campusgig.ghostsol.fun)
