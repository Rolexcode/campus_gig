Highest-priority launch gates

  1. Move signing keys out of the Vercel runtime into policy-controlled KMS/MPC or user-authorized signing.
  2. Add LiteSVM/local-validator account tests, adversarial fuzzing, reproducible SBF builds, and a verified Devnet deployment.
  3. Put upgrade and dispute authority behind separate multisigs with dual-control resolution.
  4. Migrate away from the vulnerable Solana Web3 1.x dependency line.
  5. Add a durable, idempotent chain-to-database reconciliation worker and drift alerts.

Verification checkpoint

40 TypeScript tests, lint, the Next.js production build, Rust formatting, seven Rust tests, and Clippy with warnings denied pass at this revision. npm audit --omit=dev still reports three high and twelve moderate production dependency advisories; no forced downgrade was applied.

This is an internal review, not an independent smart-contract audit. The detailed finding record is in docs/security-audit-2026-09-25.md.
